# Jira Upgrade Tools

Extensão Chrome/Chromium com melhorias de usabilidade para o Jira Cloud.

## Funcionalidade atual

- Colapsar e expandir colunas do board.
- Mantém as colunas colapsadas após recarregar a página.
- Funciona com navegação dinâmica do Jira (SPA).

## Instalação local

1. Abra `chrome://extensions`.
2. Ative **Modo do desenvolvedor**.
3. Clique em **Carregar sem compactação**.
4. Selecione a pasta deste repositório.

A extensão atua somente em `https://*.atlassian.net/*`.
